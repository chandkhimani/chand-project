📘 Pattern Generator & Number Analyzer (Python)

📖 Project Overview

Pattern Generator & Number Analyzer is a menu-driven Python application developed to demonstrate the core concepts of Python programming. The project combines pattern generation and number analysis into a single interactive application, allowing users to learn programming concepts through practical implementation.

The application provides a user-friendly menu where users can generate different star patterns, analyze numbers as even or odd, calculate the sum of numbers within a specified range, and exit the program safely.
